# 🎵 StreamSongs

Serene, minimalist, and intelligent generative lo-fi ambient music stream harmonized with real-time weather and diurnal sky cycles.

Built with **React 18**, **TypeScript**, **Vite**, and **Web Audio API**.

---

## ✨ Features

- **Algorithmic Music Generation**: Dynamic harmonic progressions, voice-leading, and motivic melodies tailored to time of day and station vibes.
- **Instrument-Adaptive Soundscapes**: 7 synthesized Web Audio instruments (Warm Rhodes FM, Glass Kalimba, Lush Analog Pad, Bamboo Flute, Acoustic Harp, Neon Synthwave Lead, 8-Bit Chiptune) with matching Pad and Bass synthesis.
- **Global Timezone Synchronization**: Clock, date, sky gradients, celestial sun/moon paths, and music period synchronize directly with any selected city across the world via Open-Meteo.
- **Procedural Canvas Visualizer**: Ambient sky, twinkling stars, wind-swept clouds, rain, snow, fog, lightning, and real-time audio spectrum analyzer bars.
- **Glassmorphic Peaceful UI**: Accordion drawer cards for Location, Weather, Wind, and Instrument; floating popover for BPM; interactive key shuffle with glowing pin lock.
- **Fully Responsive**: Fluid layout for mobile phones, tablets, and widescreen desktop monitors.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/bayusetiawan42/streamsongs.git
cd streamsongs

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
